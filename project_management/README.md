## Purpose

This folder contains planning and coordination artifacts for the LangChain demo. Use it to align on vision, scope, milestones, and day-to-day tasks.

## Contents

- `ROADMAP.md` — phased plan with milestones and acceptance criteria
- `BACKLOG.md` — prioritized, actionable tasks with owners/placeholders

## Working Agreements

- Keep items concise and actionable; prefer checklists.
- Update status via checkboxes and dates in place.
- Add decisions as bullets under the relevant milestone or task.

## How to Propose Changes

1. Edit `BACKLOG.md` for new tasks; keep phases aligned with `ROADMAP.md`.
2. If scope changes, update `ROADMAP.md` first, then tasks.
3. Reference tasks in commits like: `chore: P1-API implement /generate endpoint (#task-id)`.
